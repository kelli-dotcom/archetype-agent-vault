# Scoop Docs (PRs & Post-Mortems)
1. Inspect recent git diffs to capture what actually changed.
2. Output: **What changed**, **Why**, **How to test**, and **Breaking changes**.
3. For incidents, document root cause, impact, fix, and prevention without sugarcoating.
