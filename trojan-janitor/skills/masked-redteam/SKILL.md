# Masked Red-Team (Security & Bug Hunting)
1. Search for hardcoded keys, tokens, or committed `.env` files.
2. Audit auth checks on sensitive routes and test forms against malformed inputs.
3. Rate each finding on the `👃 Sniff Scale` with severity and a concrete fix.
