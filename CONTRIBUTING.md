# Contributing to Archetype Agent Vault

We welcome new IP-safe archetype suites, workflow skills, and terminal FX improvements.

## Strict IP-Safe Rule
- **Zero** movie/TV titles, copyrighted character names, or verbatim quotes.
- Use original archetype names and coding-native action hooks only.
- Keep one skill per job so triggers in `AGENTS.md` never collide.

## Submitting a Pull Request
1. Fork the repo and create a feature branch.
2. Scaffold new archetypes using `casting-director/SKILL.md`.
3. Complete the IP-safe checklist in the Pull Request template.
