# Mistakes & Guardrails (`mistakes.md`)

## Never Repeat
1. **Missing Root Agent Entrypoints:** Every public repo MUST ship visible `AGENTS.md`, `llms.txt`, `HANDOFF.md`, and `mistakes.md` at the root so any model can orient in one read.
2. **Unbounded Persona Fluff:** Keep every archetype grounded in crisp, testable acceptance criteria—personality sharpens focus, never replaces verification gates.
3. **Unverified Claims:** Never mark an archetype workflow complete without running its concrete verification command.
